# eason-sales-assistant

Eason（广州隆安律所执业律师）自研的 WorkBuddy 销售助手技能集，面向律师获客、案件转化与客户经营场景。

## 包含的技能

- `eason-sales-assistant`：总控 / 编排
- `eason-sales-assistant-benefit`：价值与收益表达
- `eason-sales-assistant-close`：成交 / 促单
- `eason-sales-assistant-communicate`：沟通话术
- `eason-sales-assistant-due-diligence`：需求诊断 / 尽职调查
- `eason-sales-assistant-followup`：客户跟进
- `eason-sales-assistant-identify`：客户识别
- `eason-sales-assistant-longgame`：长期经营
- `eason-sales-assistant-motion`：提案 / 演示
- `eason-sales-assistant-objection`：异议处理
- `eason-sales-assistant-quote`：报价
- `eason-sales-assistant-relationship`：关系维护

## 安装方法

### 方式一：git clone（推荐，便于后续更新）

```bash
git clone https://github.com/easonzhangyis-coder/eason-sales-assitant.git
cp -R eason-sales-assitant/eason-sales-assistant* ~/.workbuddy/skills/
```

### 方式二：下载 ZIP

1. 打开 https://github.com/easonzhangyis-coder/eason-sales-assitant
2. 点击 Code → Download ZIP，解压
3. 把解压目录里的 `eason-sales-assistant*` 各文件夹整体复制到 `~/.workbuddy/skills/`

复制完成后重启 WorkBuddy，即可在对话中调用这些技能。

## 说明

本仓库仅包含 `eason-sales-assistant` 系列技能，不含其他技能。
